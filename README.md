# miniRT

**miniRT** is a ray tracer for the 42 curriculum. It renders basic shapes with lighting using clean C and the **minilibX** library.

<p align="center">
  <img src="https://github.com/sjapi/miniRT/blob/main/readme_example.png" width="800" />
</p>

---

## Shapes

- Sphere
- Plane
- Cylinder
- Cone

## Features

- Diffuse shading
- Specular highlights
- Skybox

---

## Build & Run

```bash
make
./miniRT scenes/sp.rt
```
